سامانه ثبت و پیگیری شکایات

رابط کاربری اولیه سامانه ثبت، مدیریت و پیگیری شکایات.

امکانات فعلی

- رابط کاربری فارسی و راست‌چین (RTL)
- طراحی Dark Glassmorphism
- حالت Dark / Light
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- صفحه اصلی و معرفی امکانات
- داشبورد نمایشی
- پنجره ورود
- فرم ثبت شکایت
- فرم پیگیری پرونده
- انیمیشن‌های ورود عناصر به صفحه

وضعیت پروژه

این نسخه، نسخه اولیه رابط کاربری است و هنوز به Backend و دیتابیس واقعی متصل نشده است.

برنامه توسعه

- ورود و احراز هویت با OTP
- ثبت واقعی شکایت
- تولید کد پیگیری
- ذخیره اطلاعات در دیتابیس
- امضای درخواست
- پنل کاربری
- پنل مدیریت
- مدیریت مراحل رسیدگی
- ثبت رویدادها و سوابق تغییرات
- مدیریت فایل‌های پیوست
- ارسال اعلان و پیامک
- اتصال به سرویس‌های Cloudflare
